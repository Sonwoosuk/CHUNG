# 충남문화관광재단 클론 코딩

충남문화관광재단(cnctf.or.kr) 웹사이트를 HTML·CSS·JavaScript로 따라 만든 클론 코딩 프로젝트입니다.

## 프로젝트 소개

- **프로젝트명** : 충남문화관광재단 웹사이트 클론 코딩
- **한 줄 소개** : 공공기관 웹사이트를 분석해 메인 페이지와 문화공간 서브페이지를 직접 구현한  웹사이트
- **제작 목적** : HTML과 CSS를 숙지한 뒤, 실제 사이트를 클론 코딩하며 구조 설계·레이아웃·인터랙션을 직접 구현해 보는 데 중점을 두었습니다.
- **제작 기간** : 3일
- **사용 기술** : HTML5, CSS3, JavaScript

- **스크롤 애니메이션** : WOW.js + animate.css 기반 fadeInUp 등장 효과
- **팝업** : 자동 슬라이드, 도트 인디케이터, 오늘 하루 보지 않기(localStorage)
- **반응형 레이아웃** : 데스크탑·태블릿·모바일 대응

## 문제 해결 과정

- **사이드바 `<br>` 줄바꿈 문제** : 세로 텍스트 사이드바를 만들 때 `<br>` 태그로 줄바꿈을 처리했더니 글자 간격과 정렬이 의도와 다르게 깨졌습니다. CSS의 `writing-mode`와 letter 간격 조정으로 마크업이 아닌 스타일로 줄바꿈을 처리해 해결했습니다.
- **JavaScript 실행 시점 문제** : 슬라이더·서브 네비·팝업이 동작하지 않는 문제가 있었는데, 스크립트가 DOM이 준비되기 전에 실행되어 요소를 찾지 못한 것이 원인이었습니다. 전체 로직을 `DOMContentLoaded` 안으로 옮겨 해결했습니다.

- **서브 네비게이션 구조 깨짐** : `<ul>` 안에 슬라이더용 `<div>`를 넣었더니 브라우저가 DOM을 재구성하며 레이아웃이 무너졌습니다. 슬라이더를 `<ul>` 밖의 별도 래퍼로 분리해 해결했습니다.

- **모바일 서브 네비 잘림** : 좁은 화면에서 네비게이션이 화면 밖으로 잘려 보이지 않았습니다. 모바일에서는 가로 스크롤 대신 줄바꿈(`flex-wrap`) 방식으로 전환해 모든 메뉴가 보이도록 했습니다.

- **팝업 닫기 동작 문제** : 오버레이의 `pointer-events`와 `opacity`만으로는 닫힌 뒤에도 클릭이 막히거나 잔상이 남았습니다. `visibility`와 `display` 처리를 함께 적용해 해결했습니다.

## 회고

처음 해본 클론 코딩이었다. 단순히 화면을 똑같이 따라 그리는 작업이라고 생각했지만, 실제로는 레이아웃을 어떻게 나눌지, 어떤 단위로 컴포넌트를 만들지, 반복되는 요소를 어떻게 공통화할지 끊임없이 고민해야 하는 과정이었다.
데스크톱 페이지에서 발견하지못한 모바일에서의 문제점이 많아서 수정하는 과정에서 반응형을 고려해서 구조를 잘짜야 한다고 느끼고 생각 할 수있는 시간이였다.
완성된 결과물보다, 막힌 부분을 하나씩 뜯어보며 원인을 찾아가는 과정에서 더 많이 성장했다고 느낀다. 다음에는 컴포넌트를 더 체계적으로 분리하고, 처음부터 반응형을 고려한 구조로 시작해 보고 싶다.
